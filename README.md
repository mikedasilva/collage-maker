# Collage Maker

A browser-only collage maker. Drop, paste, or pick photos, choose a layout, and save a PNG/JPEG — nothing is uploaded anywhere.

**Live:** https://mikedasilva.github.io/collage-maker/

- Layouts: grid, mosaic, rows, columns, featured
- Social and 300 DPI print size presets, or custom sizes
- Spacing, outer border, corner radius, grid color / transparent background
- Drag to reposition a photo, scroll to zoom, Shift+drag to swap photos

No build step — open `index.html` locally or serve the folder statically.
